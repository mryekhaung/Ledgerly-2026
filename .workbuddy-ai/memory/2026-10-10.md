## First CI run (38047092523) — diagnosis and fixes
Resolved versions it proved: `material_ui` 1.6.0, `cupertino_ui` 1.1.2, `flutter_riverpod` 3.4.3,
`get_it` 9.3.0, `go_router` 17.5.0, `intl` 0.20.3. Pinned those in `pubspec.yaml` (were `any`).
Genuine compile errors found and fixed:
- Missing imports for `AppPlatform` (`app.dart`) and `AppEnvironment` (`di/injection.dart`).
- `CupertinoPageTransitionsBuilder` is in `package:cupertino_ui/cupertino_ui.dart` (exported by
  `src/route.dart`), NOT `material_ui`. Added the import.
- `AdaptiveStyle.fallback()` assigned `child`, but `child` is a `super` param → must use
  `super(child: ...)`.
- `context.goNamed(...)` is a go_router extension on `BuildContext`, not an `Element` member →
  use `GoRouter.of(context).goNamed(...)`.
- `.fontSize` / `.fontWeight` cannot be read in a `const` list (const eval can't touch instance
  members) → use `final`. `FontWeight.index` is deprecated → `.value`.
- `FontFeature`/`FontWeight`/`Color` come transitively from `material_ui` (via `flutter/painting`
  → `basic_types.dart` show-list). Do **NOT** `import 'dart:ui'` — it's flagged unnecessary.
- Added `android/app/src/main/res/values/strings.xml` — manifest used `@string/app_name` but only
  the per-flavor Gradle `resValue` defined it; the base `main` source set had no default.
  (CI does not build Android, so this would only have blown up at first `flutter build`.)
